# Sandwich

A workout tracker. React 18 + TypeScript + Vite, deployed to GitHub Pages.

## Writing user-facing text

Applies to all copy in the app: stat explainers, scan analyses, section notes,
empty states, button labels.

- Plain and boring. State the fact, stop.
- Label every number with what it is: "fat mass is 31.5 lb", not "31.5 lb".
- No em dashes.
- No rhetorical constructions: no "X, not Y", no "the thing that does Z", no
  sentence whose job is emphasis rather than information.
- American spelling.
- Figures that appear together must reconcile. Round them all the same way.

## Comments

Explain why, not what. Record measured values where a number was solved against
a render rather than reasoned.
